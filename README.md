# Sales & Revenue Analysis Dashboard

An interactive Power BI dashboard analysing two years of retail sales (Jan 2025 to Sep 2026).

[View the dashboard (PDF)](dashboard.pdf)

## What it shows
- KPIs: total revenue, orders, units sold, average order value, gross margin
- Monthly revenue trend and revenue by category
- Top products, revenue by region, and a product table
- Slicers for date, region and category

## Files
- `sales-revenue-dashboard.pbix`: the Power BI report (open in Power BI Desktop)
- `sales_data.csv`: sample dataset (synthetic)

## Tools
Power BI Desktop, DAX, Power Query
